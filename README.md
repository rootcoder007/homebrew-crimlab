# Homebrew tap for crimlab

```sh
brew install rootcoder007/crimlab/crimlab
```

or

```sh
brew tap rootcoder007/crimlab
brew install crimlab
```

crimlab is a Statistical Toolkit for Criminology and Sociolegal Research.
The formula installs the `crimlab` command and the library libcrimlab,
which run every function of the R and Python packages crimlab on JSON or
CSV input. Documentation: <https://crimlab.dev/>.

The formula is written by the crimlab release workflow when a release is
published, from the release tarball and its SHA-256; its source is
`packaging/brew/crimlab.rb` in
[rootcoder007/crimlab](https://github.com/rootcoder007/crimlab).
